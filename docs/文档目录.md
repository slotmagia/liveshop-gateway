# Gateway `docs`

本目录是 **Gateway 仓库根** 的规范入口。Gateway 不是业务模块，但 Host 与数据面必须遵守同一套通用开发规范。

| 文档 | 用途 |
|---|---|
| [开发规范.md](./开发规范.md) | 通用开发规范（L1–L8）；Gateway 重点读第 1、2.3、5、7、8 章 |
| [命名规范检查.md](./命名规范检查.md) | Gateway 无业务 operation；Host 不得发明第三套 URL |
| [命名规范检查提示词.md](./命名规范检查提示词.md) | Host 路径约束的检查提示词 |
| [容器部署.md](./容器部署.md) | Gateway 与四端 Host 本地容器、端口、up-local/down-local |
| [../business/AGENTS.md](../business/AGENTS.md) | Gateway 硬约束（无状态、CORS、Host 不得改业务） |

Gateway 不建 `protocol/`、不建 `模块开发规范.md`、不拥有业务 capability。
