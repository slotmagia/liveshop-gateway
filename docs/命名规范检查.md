# Gateway 与命名规范

Gateway **不是**业务发布模块，没有 `module.json` HTTP operation，不接 `verify-naming.ps1`。

Host 与数据面仍不得发明第三套业务 URL：

- 只按 Registry 活动 Manifest 的 method+path 转发。
- 不要在 Host 里把模块 API 改写成旧 `/console` `/commercial` `/api` `/anchor` 前缀。
- 页面菜单 URL 来自 contribution `route`，与 API path 本来就可以不同。

Gateway 不评审其他模块的命名。Host 约束以本仓库 [`开发规范.md`](./开发规范.md) 第 5、6 章为准。
